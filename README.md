### What is FileConvy?

[FileConvy](https://www.fileconvy.com?utm_source=github&utm_medium=directory) is a free website with 74 online file tools for PDFs, images, text, developers and everyday calculations. Everything works in a normal web browser, so nothing needs to be installed. Most tools upload your file over HTTPS and delete it as soon as the result is ready; a few (HEIC to JPG, Video to MP3, Image Upscaler and developer tools such as the JWT decoder and hash generator) run entirely in your browser.
